Kebijakan Privasi

Diperbarui 9 Oktober 2026

Kantong adalah aplikasi pencatatan keuangan pribadi. Halaman ini menjelaskan data apa yang disimpan, di mana, dan siapa yang bisa mengaksesnya.

Tanpa masuk akun

Kalau kamu memakai Kantong tanpa masuk, semua catatan disimpan di browser perangkatmu saja dan tidak dikirim ke server mana pun. Catatan itu akan hilang bila data browser dihapus, jadi unduh cadangan secara berkala lewat menu Data & Cadangan.

Dengan akun Google

Saat kamu masuk dengan Google, Kantong menyimpan:

  • Nama dan alamat email dari akun Google-mu, untuk mengenali akunmu.
  • Catatan yang kamu masukkan sendiri: transaksi, dompet, kategori, anggaran, tagihan rutin, dan target tabungan.

Kantong tidak meminta akses ke Gmail, Drive, kontak, atau rekening bankmu, dan tidak pernah menyimpan kata sandi Google-mu.

Scan struk

Foto struk dibaca langsung di perangkatmu. Gambar struk tidak diunggah atau disimpan di server Kantong. Hanya hasil yang kamu simpan, seperti jumlah, tanggal, dan catatan, yang ikut tersimpan seperti transaksi biasa. Saat pertama kali dipakai, browser mengunduh program pembaca teks dan data bahasa dari jsDelivr.

Di mana data disimpan

Data akun disimpan di database Supabase. Setiap baris data terkunci ke akunmu dengan aturan keamanan database (Row Level Security), sehingga pengguna lain tidak bisa membaca atau mengubahnya.

Pengelola Kantong, sebagai pemilik database, secara teknis dapat mengakses data tersebut. Pengelola tidak akan membaca, menjual, atau membagikan datamu, kecuali bila diwajibkan hukum.

Yang tidak kami lakukan

  • Tidak ada iklan.
  • Tidak ada pelacak analitik pihak ketiga.
  • Data tidak dijual atau dipakai untuk tujuan lain.

Menghapus data

Kamu bisa menghapus semua catatan kapan saja lewat Data & Cadangan → Hapus semua. Untuk menghapus akun sepenuhnya, hubungi pengelola lewat halaman GitHub Kantong.

Perubahan

Bila kebijakan ini berubah, tanggal di atas akan diperbarui.
